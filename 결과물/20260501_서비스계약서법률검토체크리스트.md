# SMBL-FLC 서비스 계약서 법률 검토 체크리스트
**작성 기준: 2026년 5월 | STRICTLY CONFIDENTIAL**

---

## 검토 목적
5월 2주 서명 예정인 SMBL-FLC 서비스 계약서의 법적 리스크를 사전 차단하고,
SMBL의 책임 분리 구조(Legal Shield)가 계약서에 완전히 반영되었는지 확인한다.

---

## PART A — 필수 삽입 조항 체크리스트 ✅

### A1. Consultant Reliance Clause (정보 신뢰 조항)
- [ ] FLC가 제공하는 모든 데이터·문서의 진위 검증 의무가 SMBL에 없음을 명시
- [ ] SMBL은 정보 전달자(Information Conveyor) 역할에 한정됨을 선언
- [ ] FLC 제공 정보에 근거한 투자자 손해에 대해 SMBL 면책 명시
- [ ] 정보 허위 판명 시 계약 즉시 해지 조항 포함

### A2. Indemnity Agreement (면책 조항)
- [ ] FLC → SMBL 전방위 면책(Indemnity) 조항 삽입
- [ ] 자산 가치 변동으로 발생하는 손해배상 청구권 SMBL 대상 사전 포기 명시
- [ ] 채권단 법적 조치로 발생하는 모든 비용에서 SMBL 면책
- [ ] 제3자(투자자) 손해 발생 시 FLC 단독 책임 조항

### A3. Non-Reliance Framework (비의존 확약)
- [ ] 투자자 배포 IM(투자설명서) 전체에 비의존 확약 적용 의무 명시
- [ ] SMBL 작성 문서는 FLC 제공 정보 기반임을 투자자에게 고지 의무화

### A4. No Cash No Deal 조항
- [ ] Retainer(착수금) 미수령 시 일체의 서비스 제공 중단 명시
- [ ] 착수금 수령 기한: 서명 후 72시간 이내
- [ ] 미납 시 계약 자동 해지 조항
- [ ] 착수금 환불 불가 조건 명시

### A5. Staged Information Gate (단계적 정보 공개)
- [ ] SMBL의 독점 구조조정 아키텍처는 법적 문서 검증 완료 후에만 공개
- [ ] 자본 조달 경로 정보는 단계별 조건 충족 후 공개
- [ ] FLC의 정보 접근 권한이 SMBL 승인 조건부임을 명시

### A6. Risk Gate 조항
- [ ] 각 Phase 진입 전 리스크 게이트 통과 의무 명시
- [ ] 리스크 게이트 미통과 시 SMBL의 일방적 계약 중단 권한
- [ ] Gia Lai 법적 문서 미제출 시 계약 범위 축소 조항

## PART B — 핵심 계약 조건 검토

### B1. 서비스 범위 (Scope of Work)
- [ ] SMBL 역할이 '자문사(Advisor)'로 명확히 한정되어 있는지
- [ ] 투자 집행 의무 또는 자본 보증 조항이 없는지
- [ ] 성공보수(Success Fee) 조건 및 산정 기준 명확히 기재
- [ ] Retainer 금액 및 지급 일정 구체적 명시

### B2. 독점 협상권 (Exclusivity)
- [ ] SMBL의 독점 에이전트 지위 명시
- [ ] 독점 기간 및 갱신 조건 구체화
- [ ] FLC의 타 에이전트 동시 고용 금지 조항
- [ ] 독점권 위반 시 위약금 조항

### B3. 기밀 유지 (Confidentiality)
- [ ] 양방향 NDA 포함 (SMBL ↔ FLC)
- [ ] 투자자 정보 외부 유출 금지 조항
- [ ] 계약 해지 후 기밀 유지 기간 명시 (최소 3년 권장)

### B4. 계약 해지 조건
- [ ] SMBL 일방 해지 권한 조건 목록 (정보 허위, 착수금 미납, Risk Gate 미통과)
- [ ] FLC 일방 해지 권한 제한 조항
- [ ] 해지 시 기지급 Retainer 반환 불가 명시
- [ ] 해지 후 SMBL의 정보 비공개 의무 범위

### B5. 준거법 및 분쟁 해결
- [ ] 준거법 명시 (베트남법 vs 싱가포르 중재 권장)
- [ ] 분쟁 해결 기관 명시 (VIAC 또는 SIAC 권장)
- [ ] 중재 비용 부담 주체 명시
- [ ] 가처분 신청 권한 SMBL 보유 조항

### C1. 즉시 삭제해야 할 조항

- [ ] SMBL이 FLC 자산의 법적 상태를 보증하는 조항 → **전면 삭제**
- [ ] FLC 채무를 SMBL이 연대보증하는 조항 → **전면 삭제**
- [ ] 투자자 손실에 대해 SMBL이 배상 책임지는 조항 → **전면 삭제**

### C2. 수정이 필요한 조항
